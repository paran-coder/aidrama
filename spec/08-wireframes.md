# 와이어프레임 명세

핵심 루프 화면(S01, S02)은 저해상도 구조로 명세한다. 나머지 화면은 단일 컬럼 폼/리스트 구조로 별도 와이어프레임 없이 화면 명세(07-screen-specs.md)의 콘텐츠 우선순위를 그대로 따른다.

## S01 대시보드 (`/dashboard`)

### 데스크톱
```
┌─────────────────────────────────────────────┐
│ [로고]        내 챌린지 | 전체현황 | 마이페이지 │  ← 글로벌 내비, 고정
├─────────────────────────────────────────────┤
│                                               │
│   ⚠ [경고 팝업 — 연속실패 2회 시에만 노출]     │  ← 조건부, 모달
│                                               │
│   ┌───────────────┐   n일 연속 🔥            │
│   │               │   1000일 중 n일째         │  ← 부엉이 이미지 + 핵심 숫자
│   │  부엉이 이미지  │   (프로그레스 바)          │     같은 시선 블록에 배치
│   │               │                          │
│   └───────────────┘                          │
│                                               │
│         [ 이번 주 업로드 제출하기 ]             │  ← 주요 행동, 큰 버튼
│         (또는: ✓ 이번 주 제출 완료)            │
│                                               │
│   이력 보기 →        전체 현황 보기 →          │  ← 보조 행동, 텍스트 링크
└─────────────────────────────────────────────┘
```

### 모바일
```
┌───────────────┐
│ ☰   [로고]     │  ← 내비는 햄버거로 축약
├───────────────┤
│  ⚠ 경고 팝업    │  ← 전체 화면 오버레이로 변경 (터치 영역 확보)
├───────────────┤
│   부엉이 이미지 │  ← 최우선, 화면 상단 고정 노출
│   n일 연속 🔥   │
│  n/1000일 바    │
├───────────────┤
│ [제출하기 버튼] │  ← 화면 하단 고정(sticky), 엄지 도달 범위
├───────────────┤
│ 이력 / 전체현황 │  ← 하단 탭 또는 축약 링크로 이동
└───────────────┘
```

**컴포넌트 후보**: 부엉이 이미지 카드(대시보드, 커뮤니티, 프로필, 완주 아카이브에서 재사용), 경고 팝업(공통 alert 컴포넌트)

## S02 업로드 제출 (`/dashboard/submit`)

### 데스크톱
```
┌─────────────────────────────────────────────┐
│ [로고]        내 챌린지 | 전체현황 | 마이페이지 │
├─────────────────────────────────────────────┤
│   이번 주 마감까지: n일 n시간                  │  ← 긴급성 우선 노출
│                                               │
│   [___________링크 입력__________] [제출]      │  ← 주요 행동
│                                               │
│   ⏳ 검증 중...                                │  ← Loading 상태
│   또는                                        │
│   ✓ 검증됨   /   ⚠ 미검증 (재시도)             │  ← Success/Partial 상태
│                                               │
│   ← 대시보드로 돌아가기                        │  ← 보조 행동
└─────────────────────────────────────────────┘
```

### 모바일
입력창과 제출 버튼을 화면 상단에 고정. 검증 상태 메시지는 입력창 바로 아래 노출해 스크롤 없이 확인 가능하게 한다.

**컴포넌트 후보**: 검증 상태 배지(검증됨/미검증 — 이력 화면에서도 재사용)

## 결정 / 근거
- **결정**: 나머지 9개 화면(가입/로그인/온보딩/커뮤니티/이력/완주/마이페이지/관리자)은 별도 와이어프레임 생략
- **근거**: 단일 컬럼 폼 또는 리스트 구조로 복잡도가 낮고, 화면 명세의 콘텐츠 우선순위만으로 구현 가능한 규모로 판단됨. 필요 시 구현 단계에서 화면 명세를 기준으로 바로 UI 변환
