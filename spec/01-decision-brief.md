# 결정 브리프 — AI드라마 챌린지 관리 서비스 (가칭)

## 배경과 해결할 문제
AI드라마 영상을 만드는 크리에이터들은 꾸준한 업로드를 지속하기 어렵다. 이 서비스는 "1000일 동안 매주 1개 업로드"라는 장기 챌린지를 게임화된 방식으로 관리해 이탈을 줄이고 동기부여를 유지시키는 것을 목표로 한다.

## 핵심 사용자 및 이해관계자
AI드라마 영상을 제작해 SNS에 업로드하는 크리에이터 본인. 구매자/결정권자 구분 없이 사용자와 참여자가 동일하다. 단, 모집형 서비스로 운영되며 초대 코드를 통해서만 가입 가능하다.

## 사용자에게 주는 가치
장기 목표를 주 단위로 쪼개 실행을 시각적으로(부엉이 성장) 추적하고, 다른 참여자의 진행상황을 보며 서로 자극받을 수 있다.

## 대표 성공 지표
- 사용자 관점: 1000일 동안 매주 1회 업로드를 이어가는 것
- 서비스 관점 (미해결): 오픈 후 참여자 수, 리텐션 등 구체적 지표는 아직 미정

## 필수 제약과 위험
- GitHub에 올려 Vercel로 배포 예정. 회원 데이터·챌린지 기록을 위한 별도 DB(Supabase, Neon, Vercel Postgres 등)가 필요함
- SNS 업로드 링크의 완전 자동 검증은 플랫폼 API 제약으로 어려울 수 있음 → 검증 실패 시 자기신고로 자동 전환하는 방식으로 완화
- 관리자는 본인 1인만 소유

## 명시적 비목표
- 결제/구매 기능 없음
- 누구나 가입 가능한 오픈형 서비스 아님 (초대 코드 기반 모집형)
- 관리자의 콘텐츠 심사 기능 없음 (초대 코드 발급/관리만 수행)

## 결정 / 근거 / 가정 요약

| 구분 | 내용 |
|---|---|
| 결정 | 연속실패 기준으로 페널티 카운트, 하락분은 다음 1회 성공 시 즉시 회복 |
| 결정 | 알 리셋 시에도 1000일 경과 카운트는 유지됨 (성장 단계만 리셋) |
| 결정 | 주간 마감은 일요일 23:59, 판정 주차는 월요일~일요일 |
| 결정 | 가입/온보딩 완료 즉시 경과일 0일차 시작, 주간 판정은 가입 주를 제외하고 다음 월요일부터 시작 |
| 결정 | 업로드 인증은 자동 링크 검증 우선, 실패 시 자기신고로 인정 + "미검증" 배지 |
| 결정 | 가입은 1코드-1인 매칭 초대 코드로만 가능 |
| 가정 | 별도 마감일/예산/필수 기술 스택 제약 없음 |
| 미해결 | 서비스 자체의 성공 지표(참여자 수 등) |
