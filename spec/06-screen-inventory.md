# 화면 인벤토리

| 화면 | 주요 상태/예외 |
|---|---|
| 랜딩 (`/`) | 기본, 로그인 상태면 대시보드로 리다이렉트 |
| 로그인 (`/login`) | 기본, 유효성 오류, 세션 만료 후 재접속 |
| 회원가입 (`/signup`) | 기본, 초대 코드 오류(만료/이미 사용됨/존재하지 않음), 유효성 오류, 완료 |
| 온보딩 (`/onboarding`) | 기본(알 등록 안내), 완료 |
| 대시보드 (`/dashboard`) | 기본(진행 중), 경고 상태(연속실패 2회 팝업), 완료 상태(1000일 도달), 로딩 |
| 업로드 제출 (`/dashboard/submit`) | 기본, 유효성 오류, 검증 중(로딩), 검증 실패(미검증 전환), 중복 제출 방지, 제출 성공 |
| 이력 (`/dashboard/history`) | 기본, 빈 상태 |
| 전체 현황 (`/community`) | 기본, 빈 상태, 로딩 |
| 다른 사용자 프로필 (`/community/:userId`) | 기본, 존재하지 않는 사용자(404) |
| 마이페이지 (`/mypage`) | 기본, 저장 성공/실패 |
| 완주 아카이브 (`/complete/:userId`) | 기본, 완주 전 접근 시 리다이렉트/404 |
| 관리자 초대 코드 (`/admin`) | 기본, 권한 부족, 코드 발급 성공/실패, 빈 상태 |
