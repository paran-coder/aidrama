# 범위와 우선순위

| 구분 | 항목 |
|---|---|
| **Must** | 회원가입(초대 코드 검증)/로그인, 챌린지 시작(알 상태로 등록), 주간 업로드 기록(SNS 링크 자동 검증 + 자기신고 폴백), 연속일수(스트릭) 계산 및 표시, 부엉이 성장 단계 시각화(일자별), 실패 단계별 페널티(1회 하락/2회 경고/3회 리셋) 및 즉시 회복 로직, 개인 진행 현황 페이지, 전체 참여자 현황 페이지, 관리자 초대 코드 발급/관리, 회원가입 시 초대 코드 검증 |
| **Should** | 마일스톤 배지(30일·100일·365일 등 성장 구간), 업로드 마감 전 알림, SNS 공유용 카드 이미지 자동 생성, 다른 참여자 응원(댓글/좋아요) |
| **Could** | 팀/그룹 챌린지, 리더보드 정렬·필터, 상세 통계 대시보드(그래프) |
| **Not now** | 결제/유료 기능, 관리자 콘텐츠 심사 화면 |

## 결정 / 근거 / 가정

- **결정**: 회원가입/로그인을 Must에 포함
  **근거**: 개인 페이지와 전체 페이지를 구분하려면 계정 식별이 필요함
- **결정**: 관리자 초대 코드 발급/관리를 Must에 포함
  **근거**: 모집형 서비스 운영 방식으로 확정됨 (누구나 가입 불가)
- **가정**: 로그인 방식(이메일/소셜 등) 세부사항은 구현 단계에서 결정
